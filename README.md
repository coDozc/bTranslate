# bTranslate

Windows için masaüstü çeviri uygulaması. PDF, tarayıcı veya başka bir uygulamada seçtiğiniz metni kısayolla ya da seçimin yanında çıkan **Ç** simgesiyle çevirir. Seçilemeyen yazılar için ekran alanı seçimi ve Windows OCR desteği vardır. Çeviri, farenin yanında taşınabilir ve boyutlandırılabilir bir kutuda gösterilir; uygulama sistem tepsisinde çalışır.

## İndir ve kur

1. Bu sayfadaki **Releases** bölümünden en yeni `bTranslate-Setup-win-x64-*.exe` dosyasını indirin. GitHub'ın otomatik oluşturduğu **Source code** ZIP dosyaları uygulamayı içermez.
2. Kurulum dosyasını çalıştırın. Kurulum bitince **bTranslate** uygulamasını Başlat menüsünden veya masaüstü kısayolundan açın.
3. Kurulum veya kullanım için .NET yüklemeniz gerekmez. Windows 10/11, 64 bit gerekir.

Kurulum dosyası şu anda dijital olarak imzalı değildir; Windows indirme veya çalıştırma sırasında SmartScreen uyarısı gösterebilir. Dosyayı yalnızca bu deponun Releases bölümünden indirin. Aynı sürüme ait `.sha256` dosyası bütünlük kontrolü içindir.

Varsayılan seçili metin kısayolu **Ctrl+Alt+F8**, ekran alanı kısayolu **Ctrl+Alt+F9**'dur. Ayarlardan kaynak/hedef dili, çeviri servisini ve kısayolları değiştirebilirsiniz. Uygulamayı tamamen kapatmak için sistem tepsisi simgesine sağ tıklayıp **Çıkış**'ı seçin.

Varsayılan Google Web ve isteğe bağlı Yandex Web servisleri API anahtarı istemez. Bu servisler resmî bulut API'leri değildir; erişimleri değişebilir. Seçtiğiniz metin, çeviri için seçili çevrimiçi servise gönderilir. Yerel Ollama ve LibreTranslate seçenekleri de vardır; bunlar ayrıca kurulmalıdır.

Bu depoda indirme ve kullanım bilgileri bulunur; uygulamanın kaynak kodu yayımlanmamıştır.
