# bTranslate 0.1.0

İlk Windows kurulum sürümü.

- Seçili metni kısayolla veya seçim yanında çıkan simgeyle çevirme
- Seçilemeyen metin için ekran alanı ve OCR
- Taşınabilir, boyutlandırılabilir ve saydamlığı ayarlanabilir sonuç kutusu
- Sistem tepsisinden çalışma ve çeviri servisi değiştirme
- Anahtarsız Google Web ve Yandex Web seçenekleri; tek kelimede Yandex boş yanıt verirse Google Web'e geçiş

**İndirme:** `bTranslate-Setup-win-x64-0.1.0.exe` dosyasını Releases bölümünden indirin. Kurulum için Windows 10/11 64 bit gerekir; .NET ayrıca yüklenmez.
